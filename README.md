# 2048 · Закат

Лабораторная работа №3: игра 2048 на чистом HTML, CSS и JavaScript.

## Возможности

- поле 4×4 генерируется через JavaScript;
- управление: стрелки на клавиатуре (компьютер), свайпы (телефон);
- подсчёт очков, лучший результат, отмена хода, новая игра;
- проверка окончания игры, сохранение рекорда, таблица топ-10;
- сохранение игры и рекордов в localStorage;
- анимации движения, слияния и появления плиток.
